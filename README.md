# Repositorio PAP: Robots Unitree G1 EDU y Go2

Este repositorio contiene la documentación técnica, evidencias, guías de instalación, archivos de simulación y códigos desarrollados durante el Proyecto de Aplicación Profesional enfocado en los robots Unitree G1 EDU y Unitree Go2.

## Objetivo

Facilitar la continuidad del proyecto para futuras generaciones del PAP, reduciendo la curva de aprendizaje en la configuración, operación y desarrollo de pruebas con las plataformas robóticas Unitree G1 EDU y Go2.

## Estructura del repositorio

- `Documentos/`: manuales técnicos, guías de instalación y documentación del proyecto.
- `Evidencias/`: imágenes, capturas y videos relacionados con las pruebas realizadas.
- `IsaacSim_Isaac_Lab/`: archivos y documentación relacionados con Isaac Sim e Isaac Lab.
- `IsaacSim_Isaac_Lab/Secuencias_Exportadas/`: secuencias generadas o adaptadas desde simulación.
- `Scripts/G1/`: códigos desarrollados para pruebas con el robot Unitree G1 EDU.
- `Scripts/Go2/`: códigos desarrollados para pruebas con el robot Unitree Go2.

## Contenido principal

El repositorio incluye procedimientos de configuración de Ubuntu, conexión por Ethernet y WiFi, comunicación mediante SSH, uso del SDK de Unitree, pruebas de movimiento, documentación de simulación y registro de errores frecuentes encontrados durante el desarrollo.

## Estado del proyecto

Proyecto desarrollado durante el periodo de verano 2026 como parte del PAP del ITESO.
